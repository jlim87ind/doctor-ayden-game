# Changelog

## Release 2 — 26 September 2026

Made for playing on an iPad by children aged 4–9, including children who cannot read yet.

- **New characters.** Outlined “sticker” characters with sleeves, hands, faces that blink, and a different hairstyle for each patient. Patients lie in bed under a blanket, and lie on the procedure table and recovery couch.
- **Sharp on tablets.** Every canvas draws at the screen's full resolution.
- **Fits one screen.** While playing, the clinic, the top bar and the bag fit on an iPad with no scrolling. The site header hides; Mute and Settings move into the top bar.
- **Thumb pad is optional.** It is off by default, so it no longer covers the map. Turn it on in Settings → Thumb pad. Tapping the floor always works.
- **Spoken hints.** Each new task is read aloud once, when no other voice is playing. A speaker button replays the hint, the patient's words, and each mini-game instruction. 8 new voice clips name the supply to fetch (for example, “Look for the sun picture”). Map labels are bigger.
- **Fair on slow tablets.** “Hold” tasks and walking use real clock time. The blur behind pop-ups is removed, because it slowed the game down.
- **Knee and arm close-ups.** Scrape, bump and arm care show the real knee or arm in the patient's own skin tone. The scrape fades as you clean it, and the comfort patch builds up star by star.
- **Drawn icons.** 41 original icons replace every colour emoji, so pictures look the same on every device.
- **Offline and home-screen app.** After one visit online, the game works with no internet, including all sounds. On an iPad: Safari → Share → Add to Home Screen.
- **Tidier code.** The source is formatted with Prettier (`npm run format`).
